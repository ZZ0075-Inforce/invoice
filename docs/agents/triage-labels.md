# Triage 標籤

各 skill 以五個 canonical triage 角色溝通。本檔把角色對應到本 repo issue tracker 實際使用的標籤字串。

| mattpocock/skills 的標籤 | 本 repo 的標籤 | 意義 |
| ------------------------ | ------------------ | ---------------------------- |
| `needs-triage`           | `needs-triage`     | 待維護者評估                 |
| `needs-info`             | `needs-info`       | 等回報者補充資訊             |
| `ready-for-agent`        | `ready-for-agent`  | 規格完整，可交給 AFK agent   |
| `ready-for-human`        | `ready-for-human`  | 需要人工實作                 |
| `wontfix`                | `wontfix`          | 不處理                       |

skill 提到某個角色時（例如「apply the AFK-ready triage label」），用表中對應的標籤字串。

日後標籤改名，改右欄即可。
